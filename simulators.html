RISC-V simulators

Four educational simulators that follow the Patterson and Hennessy textbook, RISC-V edition, from how a number is stored to how many cores share memory. They are used in the Computer Organization course at UFT, run entirely in the browser with nothing to install, and offer Portuguese and English interfaces with a light theme and a high contrast dark theme.

RISC-V Floating Point Simulator

Chapter 3
arithmeticIEEE 754fixed pointinteger algorithms
  • Any number converted bit by bit to double, single, half, bfloat16 and the two 8 bit OCP formats, with the stored value, the error in ULPs and the guard, round and sticky bits.
  • fadd, fmul, fdiv, fsqrt and fmadd shown as the hardware steps, under the five RISC-V rounding modes and stochastic rounding, with the fflags exceptions.
  • Integer multiplication and division in the textbook step tables, fixed point Qm.n formats, experiments on accumulated error and seeded exercise lists with automatic grading.

RISC-V Processor Simulator

Chapters 4 and 5
processorspipeliningTomasulomemory hierarchy
  • Runs RV32 and RV64 programs on a single cycle datapath, a five stage pipeline with forwarding, hazard detection and branch prediction, and Tomasulo with or without a reorder buffer.
  • Each step explains what happened and lights up the wires and units involved, drawn as the datapath figures of the textbook.
  • Configurable L1, L2 and L3 caches, a TLB with Sv32 and Sv39 page tables and page faults, and execution time compared through the performance equation.

RISC-V Multiprocessing Simulator

Chapters 5 and 6
multiprocessingcache coherencesnoopingA extension
  • Two to four cores with private caches on a snooping bus, under the MSI, MESI and MOESI protocols, with the same sequence compared across the three.
  • Every access animates a system figure (caches, bus and memory) and the protocol state diagram, showing the transition of the accessing core and of the caches that react.
  • RISC-V programs with lr.w, sc.w and AMOs run on all cores, with examples of a race condition, test and set and test and test and set locks, and false sharing.

RISC-V Data Level Parallelism Simulator

Chapter 6
parallelismvector extensionGPUTPU
  • A vector processor for the RISC-V V extension with up to eight lanes, chaining, strip mining, masks, strided and indexed accesses.
  • A SIMT GPU with warps, a scheduler, up to sixteen lanes, branch divergence with a reconvergence stack and memory coalescing.
  • A TPU style systolic array for matrix multiplication, including int8 quantization, a small MLP and convolution through im2col, plus a comparison of the same workload on the three models.

For the classroom

Figures for slides

The current step can be exported as an SVG figure in the textbook style, ready for slides, exams and the editors students already use.

Tables for exams

Step tables, timelines and event tables export to LaTeX, and blank versions turn any run into an exercise.

Shareable runs

A link reopens a program with its configuration, so a whole class can start from the same example.

All four simulators are free software under the GPL 3.0 license. Each one is a set of static files with no build step and no dependencies, published on GitHub Pages.
